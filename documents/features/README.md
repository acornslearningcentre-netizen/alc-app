# Feature Requirements

One file per feature area needed to make the app fully functional. Each is its own Jira Epic (there is no single umbrella epic — each feature below is independently sequenced into a sprint). Each file describes the feature from the point of view of the person using it — teacher, parent, student, school leader, or onboarding staff — with acceptance criteria in plain language.
